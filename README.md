# Ad Astra: Aeronautics Compat 
realistic planetary physics to Ad Astra dimensions when used with Create Aeronautics and Sable.

Planetary gravity, atmospheric pressure, and aerodynamic drag are adjusted based on real-world celestial bodies. Orbital dimensions are treated as vacuum environments with zero gravity and no atmospheric drag.

## Features

- Realistic gravity for Earth, Moon, Mars, Venus, and Mercury
- Planet-specific atmospheric pressure
- Vacuum conditions in orbital dimensions
- Reduced or disabled aerodynamic effects in low-pressure and vacuum environments
- No changes to Ad Astra's original dimension generation or terrain
- Implemented as a datapack through Sable's dimension physics system

Ad Astra
Create Aeronautics
Sable
